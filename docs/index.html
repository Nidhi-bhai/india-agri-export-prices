What this is

Buyers and importers ask the same question every week: "what does this cost from India right now?" Public data exists but is scattered across UN Comtrade, government mandi dashboards and seller listings. This index pulls it together once a week, shows the source and date beside every number, and never fills a gap with a guess. Each weekly snapshot is appended to history.csv, so the record gets longer every week.
