HS code 170113 is a pooled customs category: it mixes jaggery powder with other goods. Its unit value is an HS-code group average, not the price of this exact product.

Which figures are which. Official export unit value (FOB basis): UN Comtrade data. India's declared FOB export value divided by net weight, for everything shipped under one HS customs code. Where several products share one HS code we label it an HS-code group average: it is the same number for every product in that code and is not the price of any one product. Estimate: our desk range from public seller offers, trade reports and shipment records (indicative, not quotes, and not verified FOB unless the basis says so), with the number of data points (n). Ranges with n<3 are flagged low sample. Mandi price / calculated: Indian wholesale farm-gate prices, not export prices.

Questions

What is the export price of jaggery powder from India?

Our desk estimate from public seller offers and trade reports is 0.84–1.08 USD/kg (compiled 2026-10-23; indicative, not a quote). This is a low-sample figure (n=1), not a market price. The HS 170113 group average export unit value (FOB basis, UN Comtrade) was 0.80 USD/kg in Jul 2026. That code pools jaggery powder with other goods, so it is market context, not the price of jaggery powder. Firm prices depend on grade, quantity, packing and destination; email for a quote.
